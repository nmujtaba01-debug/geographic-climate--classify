# geographic-climate--classify
Beginner Python project for climate classification

## Description
This project classifies temperatures into different climate regions:
- **Cold region**: Temperature ≤ 15°C
- **Moderate region**: 15°C < Temperature < 30°C
- **Hot region**: Temperature ≥ 30°C

## Usage
Run the script to classify temperatures:
```python
python climate_classifies.py
```

## Example
The script classifies the following temperatures: `[12, 28, 36, 18, 40]`

Output:
```
12 cold region
28 moderate region
36 hot region
18 moderate region
40 hot region
```
